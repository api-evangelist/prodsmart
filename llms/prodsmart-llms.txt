# Autodesk Fusion Operations (Prodsmart)

> Cloud manufacturing execution / production management platform for small and mid-sized manufacturers (production, inventory, sales, purchasing, quality, scheduling, maintenance and analytics). Formerly Prodsmart; acquired by Autodesk in 2021 and rebranded Autodesk Fusion Operations. Exposes a documented REST API (v1 legacy, v2 on Autodesk Platform Services), webhooks and a changes feed.

## APIs
- [Fusion Operations API v2 (APS)](https://aps.autodesk.com/en/docs/fusion-operations/v2): Current API on Autodesk Platform Services.
- [Fusion Operations API v1 (legacy, deprecated)](https://fusionoperations.autodesk.com/api-documentation): Documented v1 REST reference. Base https://fusionoperations.autodesk.com, paths under /api/v1/.

## Specs

## Conventions
- Auth: HTTP Basic (API Key/Secret) mints a 2-hour token; access_token query param accepted.
- Media type: application/json. Dates: ISO 8601. Rate limit: 120 requests/minute per company.
- Integrations: Webhooks, Changes Feed Channels, Zapier, Power BI.
